# 素材と音声

このページでは、背景、立ち絵、BGM、SEなどの素材を使うときの考え方を説明します。

## 素材フォルダ

シーン編集で開くファイルピッカーは、用途ごとに既定フォルダが決まっています。

| 用途 | 既定フォルダ |
| --- | --- |
| 背景画像 | `assets/images/bg/` |
| 立ち絵画像 | `assets/images/chars/` |
| BGM | `assets/sounds/bgm/` |
| SE | `assets/sounds/se/` |

各フォルダ内にサブフォルダを作ることもできます。ファイルピッカーは、起点フォルダの内側を移動してファイルを選びます。

## 対応ファイル

| 種類 | 拡張子 |
| --- | --- |
| 画像 | `.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp` |
| 音声 | `.mp3`、`.ogg`、`.wav` |

Markdown取り込みでは `.md`、`.markdown`、`.txt` を選べます。プロジェクト読込では `.pvnm` を選びます。

## ファイルピッカー

ファイルピッカーでは、左側でファイルやフォルダを選び、右側でプレビューを確認します。

| 操作 | 内容 |
| --- | --- |
| クリック | ファイルやフォルダを選ぶ |
| `OK` | 選択中のファイルを反映する |
| `CANCEL` / `Esc` | 選択をやめる |
| `Enter` | 選択中のファイルを確定する。フォルダの場合は中へ入る |
| 上下キー | 選択を移動する |
| マウスホイール | 一覧をスクロールする |

画像はPVNMのパレット処理後の見え方でプレビューされます。音声は `PLAY` / `STOP` で試聴できます。

## 背景画像

背景画像は `SCENE` タブの `[BACKGROUND IMAGE]` から選びます。選んだ画像は `./assets/images/bg/...` としてシーンに保存されます。

| 状態 | 動き |
| --- | --- |
| 画像を設定 | このシーン以降の背景として使う |
| 空のまま | 前のシーンの背景を引き継ぐ |
| `HIDE BACKGROUND` | 背景の継承を切り、非表示にする |

`BACKGROUND FULLSCREEN` は画面全体に合わせる設定です。`BG SAFE AREA` は背景をダイアログ上の領域に収め、画像下部がメッセージウィンドウで隠れにくくなる設定です。

## 立ち絵画像

立ち絵は `CHARACTERS` タブの `LEFT`、`CENTER`、`RIGHT` それぞれで `[FILE]` から選びます。選んだ画像は `./assets/images/chars/...` としてシーンに保存されます。

| 状態 | 動き |
| --- | --- |
| 画像を設定 | このシーン以降の同じスロットに使う |
| 空のまま | 前のシーンの同じスロットを引き継ぐ |
| `HIDE CHARACTER` | そのスロットの継承を切り、非表示にする |

立ち絵は、倍率、横位置、縦位置、透過色、左右反転、上下反転、アニメーションをスロットごとに設定できます。

## COLOR KEY

立ち絵の `COLOR KEY` は透過色の扱いです。

| 値 | 内容 |
| --- | --- |
| `AUTO` | PNGのalphaなどから安全な透過色を自動で扱う |
| `NONE` | 透過色を使わない |
| `0` - `255` | Pyxelパレット番号を透過色として指定する |

通常は `AUTO` から始めて、意図しない抜けがある場合だけ調整します。

## BGM

BGMは `SCENE` タブの `[BACKGROUND MUSIC FILE]` から選びます。選んだ音声は `./assets/sounds/bgm/...` としてシーンに保存されます。

| 状態 | 動き |
| --- | --- |
| BGMを設定 | このシーンからBGMを再生する |
| 空のまま | 前のシーンのBGMを引き継ぐ |
| `STOP BGM` | 継承中のBGMを停止する |
| `PLAY BGM ONCE` | ループせず、このシーンで一度だけ再生する |

`BACKGROUND MUSIC VOLUME` で音量を調整できます。`BGM FADE OUT` は遷移時のフェードアウトフレーム数です。

## SE

SEは `SCENE` タブの `[SOUND EFFECT FILE]` から選びます。選んだ音声は `./assets/sounds/se/...` としてシーンに保存されます。

SEはシーン開始時に鳴る効果音です。BGMのように次シーンへ継承されません。

| 項目 | 内容 |
| --- | --- |
| `SOUND EFFECT VOLUME` | SE音量 |
| `SOUND EFFECT REPEAT (0=once)` | SEの繰り返し回数。0は1回再生 |

## 素材を消したいとき

背景、立ち絵、BGM、SEのファイル欄は、右クリックで選択済みファイルをクリアできます。背景や立ち絵、BGMは空にすると前シーンから継承されるため、明示的に消したい場合は `HIDE BACKGROUND`、`HIDE CHARACTER`、`STOP BGM` を使います。

## ローディング画像とアプリアイコン

プロジェクトフォルダ内に決まった名前のPNGを置くと、一部のエクスポート成果物へ反映されます。PVNMの画面から選ぶ設定項目ではなく、ファイル名と場所で自動検出する方式です。

| ファイル | 用途 | 反映先 |
| --- | --- | --- |
| `assets/images/ui/loading.png` | 起動中に表示するローディング画像 | Web HTML、Android Project/APK |
| `assets/images/ui/app_icon.png` | アプリ/実行ファイルのアイコン | macOS APP、Windows EXE、Android Project/APK |

どちらも省略できます。ファイルがない場合は、PVNMに同梱されている既定画像が使われます。

ローディング画像は、WebやAndroidの起動時にPVNMの最初の描画が終わるまで表示されます。アプリアイコンは、macOS/WindowsではPyInstallerのアプリアイコンとして使われ、Androidではランチャーアイコン用に各解像度へ変換されます。

画像はPNGで用意してください。アプリアイコンは正方形の画像にしておくと、各OS向けの変換結果が安定します。

| 用途 | 参照 |
| --- | --- |
| Web向け | [Web HTMLエクスポート](export-web.md) |
| Android向け | [Androidエクスポート](export-android.md) |
| Windows向け | [Windows EXEエクスポート](export-windows.md) |

## 色味の確認

画像の色味をPVNM向けに整えたい場合は、[色とツール](colors-and-tools.md) のVN Palette Toolを使います。最終的な見え方は、PVNMのプレビューと各エクスポート先の実行環境で確認してください。
