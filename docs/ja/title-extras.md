# タイトルとEXTRAS

このページでは、タイトル画面、エンディング、CGギャラリー、EXTRA TEXTを設定する方法を説明します。

## TITLE CONFIG

`SETTINGS` の `TITLE CONFIG` でタイトル画面を設定します。タイトル画面の画像やBGMなど、ゲーム開始前に表示される要素を調整します。

主な項目は次の通りです。

| 項目 | できること |
| --- | --- |
| `BACKGROUND IMAGE` | タイトル背景画像を選びます。右クリックで解除できます。 |
| `BACKGROUND FULLSCREEN` | 背景画像を画面に合わせて表示します。OFFの場合は原寸を中心に置き、画面より大きい場合だけ縮小します。 |
| `BACKGROUND MUSIC` | タイトル画面で流すBGMを選びます。右クリックで解除できます。 |
| `BACKGROUND MUSIC VOLUME` | タイトルBGMの音量を調整します。 |
| `BACKGROUND MUSIC LOOP` | タイトルBGMをループ再生するかを切り替えます。 |
| `BUTTON COLORS` | タイトル画面のボタン色を、256色マスターパレットの番号で設定します。 |

`BUTTON COLORS` では、通常時とホバー時の背景、枠線、文字色を個別に設定できます。変更した色はタイトル画像の減色時にも予約色として扱われるため、タイトルボタンの色が画像側の減色で潰れにくくなります。

画面下部の操作は次の通りです。

| ボタン | 動作 |
| --- | --- |
| `SAVE & CLOSE` | 設定を保存して閉じます。 |
| `REVERT ALL` | 編集開始時点の設定に戻します。 |
| `CANCEL` / `ESC` | 保存せずに閉じます。未保存の変更がある場合は破棄確認が出ます。 |
| `PLAY PREVIEW` | 現在の設定でタイトル画面を確認します。 |

## ENDING CONFIG

`ENDING CONFIG` では、ゲーム内で到達できるエンディングを登録します。登録したエンディングは、EXTRASの開放条件にも関係します。

左側の一覧でエンディングを選び、`ADD`、`COPY`、`DEL` で管理します。右側で選択中のエンディングを編集します。

| 項目 | できること |
| --- | --- |
| `NAME` | エンディング名を設定します。EXTRAS開放判定では、この登録名が到達済みとして記録されます。 |
| `CREDITS` | スクロール表示するクレジット本文を編集します。 |
| `FONT SIZE` | クレジット文字サイズを調整します。 |
| `SCROLL SPEED` | クレジットのスクロール速度を調整します。 |
| `BACKGROUND MUSIC` | エンディング中に流すBGMを選びます。 |
| `BACKGROUND MUSIC VOLUME` | エンディングBGMの音量を調整します。 |
| `BGM LOOP` | エンディングBGMをループ再生するかを切り替えます。初期値はOFFです。 |
| `GOTO ENDING` | 自然終了後に別のエンディングへ続ける場合に指定します。 |

エンディングには複数のスライドを登録できます。

| スライド項目 | できること |
| --- | --- |
| `ADD SLIDE` / `DEL SLIDE` | スライドを追加、削除します。 |
| `Image` | 表示する画像を選びます。 |
| `TIME` | スライドを表示する時刻を指定します。BGMがある場合はBGMの再生位置に同期します。 |
| `PREVIEW` | そのスライドを基準にプレビューします。 |
| `cut` / `fade` / `zoom` | スライド切り替え効果を選びます。クリックで順番に切り替わります。 |
| `E-DUR` | `fade` / `zoom` などの効果時間を指定します。 |
| `DUR` | 個別の表示時間を指定します。時刻指定が主で、互換用の表示時間として使われます。 |

エンディング画面下部では `FROM:<time>` でプレビュー開始位置を指定できます。プレビュー中に `ESC` で戻ると、その時点の時間を `APPLY TIME` でスライドに反映できます。

シーン側からエンディングへ進ませるには、シーン編集の `FLOW` で `GOTO ENDING` を指定します。エンディングが自然終了したときに、到達済みエンディングとして保存されます。

## CG GALLERY

`CG GALLERY` では、EXTRASに表示するCG画像を設定します。ギャラリーはページと3x3のスロットで構成されます。未設定のスロットは `LOCKED` として表示されます。

主な操作は次の通りです。

| ボタン | 動作 |
| --- | --- |
| `ADD PAGE` | 3x3スロットのページを追加します。 |
| `DELETE PAGE` | 現在のページを削除します。 |
| `PREV` / `NEXT` | ページを切り替えます。 |
| `SET IMAGE` | 選択中スロットに画像を登録します。 |
| `CLEAR SLOT` | 選択中スロットの画像を外します。スロット右クリックでも解除できます。 |
| `IMPORT USED` | プロジェクト内で使っている画像をまとめてギャラリーへ取り込みます。 |
| `PREVIEW` | 実際のCGギャラリー表示を確認します。 |

ページが1つ以上あると、タイトル側にEXTRAS用の項目が出る対象になります。CGギャラリー画面では、画像が入っているスロットはサムネイル、空のスロットは `LOCKED` として表示されます。

`IMPORT USED` では、取り込み範囲と取り込み方法を選べます。

| 項目 | 内容 |
| --- | --- |
| `BG+ENDING` | タイトル背景、シーン背景、背景flipbook、エンディングスライド画像を対象にします。 |
| `ALL` | `BG+ENDING` に加えて、立ち絵と立ち絵flipbookも対象にします。 |
| `APPEND` | 既存スロットを残して、空きスロットへ追加します。重複画像はスキップします。 |
| `REPLACE` | 既存ページを作り直して、取り込み結果で再構成します。 |

## EXTRA TEXT

`EXTRA TEXT` では、EXTRAS内に表示するテキストを設定します。クリア後のおまけ文章や補足資料などに使います。

ページ単位でタイトルと本文を登録します。ページが1つ以上あると、タイトル側にEXTRAS用の項目が出る対象になります。

| ボタン | 動作 |
| --- | --- |
| `ADD PAGE` | EXTRA TEXTページを追加します。 |
| `DELETE PAGE` | 現在のページを削除します。 |
| `PREV` / `NEXT` | ページを切り替えます。 |
| `EDIT TEXT` | ページ本文を編集します。 |
| `TEXT SIZE:<size>` | 表示文字サイズを切り替えます。左クリックで大きく、右クリックで小さくします。 |
| `PREVIEW` | 実際のEXTRA TEXT表示を確認します。 |

本文が1ページに収まらない場合、プレビューで `OVER LIMIT: SPLIT INTO PAGES` と表示されます。その場合はページを分けてください。

`EXTRA TEXT` には専用の色設定があります。背景、パネル、枠線、本文、薄字、アクセント、ボタン背景、ボタン文字、ボタンホバー色を256色マスターパレットから選びます。

## EXTRASの開放

EXTRASは、CGギャラリーかEXTRA TEXTのページが1つ以上あるとタイトル画面の対象になります。未開放の間はタイトル画面に `???` と表示され、選択しても開きません。

開放条件は、登録されたエンディング名をすべて自然到達で見ていることです。エンディングを登録していない場合、EXTRASは開放済みになりません。

配布前には、スタートから各エンディング到達、EXTRAS開放、CG表示、EXTRA TEXT表示まで通しで確認してください。
