# プロジェクト管理

このページでは、プロジェクトの作成、保存、読込、Markdown取り込みについて説明します。

## 新規作成

`Cmd+N`、またはWindowsでは `Ctrl+N` で新しいプロジェクトを作成します。編集中の内容がある場合は、未保存の編集を破棄する確認が表示されます。

## 保存

`Cmd+S`、またはWindowsでは `Ctrl+S` で現在のプロジェクトを保存します。まだ保存先がない場合は `.pvnm` の保存先を選びます。

別名保存は `Cmd+Shift+S`、またはWindowsでは `Ctrl+Shift+S` です。`SETTINGS > PROJECT` から `SAVE PROJECT` / `SAVE AS PROJECT` を選ぶこともできます。

## 読込

下部ツールバーの `OPEN`、または `Cmd+O` / `Ctrl+O` で既存の `.pvnm` プロジェクトを開きます。未保存の編集がある場合は、開く前に確認が表示されます。

## Markdownから取り込む

下部ツールバーの `IMPORT MD` でMarkdown形式の台本を取り込みます。

Markdown取り込みは、既存のPart、Chapter、Sceneを選択したMarkdownの内容で置き換えます。既存シーンへ追加やマージはしません。必要なら、取り込み前に別名保存してバックアップを作ってください。

取り込み後は、背景、立ち絵、BGM、SE、選択肢の遷移先などをPVNM上で調整してください。

## Markdown書式

```markdown
# Part名
## Chapter名
### Scene名

少女：わたしは……生きてる？

少年「そうだよ」

- うなずく
- 首を振る
```

| 書式 | 取り込まれる内容 |
| --- | --- |
| `# Part名` | Part |
| `## Chapter名` | Chapter |
| `### Scene名` | 次に作るシーンの表示名 |
| `話者：テキスト` | 話者付きの本文 |
| `話者「テキスト」` | 話者付きの本文 |
| 話者なしの段落 | 地の文 |
| `- 選択肢` / `* 選択肢` | 直前シーンの選択肢 |

選択肢の遷移先は空の状態で取り込まれます。取り込み後、PVNM上で各選択肢の遷移先を設定してください。

## プロジェクトファイルの扱い

PVNMのプロジェクトには、シーン情報、設定、素材参照などが含まれます。Windows EXEをGitHub Actionsでビルドする場合は、ビルドしたい状態をcommitしてpushしておく必要があります。
