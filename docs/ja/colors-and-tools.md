# 色とツール

このページでは、UIカラー、話者色、VN Palette Toolについて説明します。

## COLOR CONFIG

`SETTINGS` の `COLOR CONFIG` では、ゲーム内UIの色を設定します。メッセージウィンドウ、枠線、ボタンなど、作品全体の見た目を整えるために使います。

`COLOR CONFIG` は、256色マスターパレットの各色を「役割」に割り当てる画面です。左側にプレビュー、右側に `ROLES` / `PRESET`、下側に `MASTER PALETTE` が表示されます。

基本操作は次の流れです。

1. 右上の `ROLES` で変更したい役割を選びます。
2. 右下の `MASTER PALETTE (click to assign)` で色をクリックします。
3. 左側の `EDITOR UI` / `PLAY UI` プレビューで見え方を確認します。
4. 問題なければ `SAVE` で保存します。

画面下部のボタンは次の通りです。

| ボタン | 動作 |
| --- | --- |
| `SAVE` | 現在の色設定を保存します。 |
| `REVERT` | 編集開始時点の設定に戻します。 |
| `DEFAULT` | 役割ごとの初期色に戻します。 |
| `CANCEL` / `ESC` | 保存せずに閉じます。未保存の変更がある場合は破棄確認が出ます。 |

### EDITOR UIの役割

`EDITOR UI` はPVNMの編集画面に使われる色です。書き出したゲーム本編のプレイ画面には直接影響しません。

| 役割 | 用途 |
| --- | --- |
| `EDIT_BG` | エディタ画面の背景 |
| `EDIT_PANEL` | パネル背景 |
| `EDIT_BTN_BG` | ボタン背景 |
| `EDIT_PREVIEW_BG` | メインビュー、フローチャート背景 |
| `EDIT_BORDER` | 枠線 |
| `EDIT_TEXT_DIM` | 薄字 |
| `EDIT_TEXT` | 通常文字 |
| `EDIT_BTN_HOVER` | ボタンホバー色 |
| `EDIT_ACCENT` | 強調、アクティブ表示 |
| `EDIT_HIGHLIGHT` | 選択行ハイライト |
| `EDIT_TITLE_BG` | タイトルバー背景 |

### PLAY UIの役割

`PLAY UI` はゲーム実行中の画面に使われる色です。

| 役割 | 用途 |
| --- | --- |
| `PLAY_BG` | プレイ画面の背景 |
| `PLAY_DIALOG_BG` | ダイアログボックス背景 |
| `PLAY_BORDER` | 枠線 |
| `PLAY_TEXT_DIM` | 薄字 |
| `PLAY_TEXT` | 通常本文色 |
| `PLAY_ACCENT` | 強調、アクティブ表示 |
| `PLAY_HIGHLIGHT` | ハイライト帯 |
| `PLAY_SPEAKER_FG` | 話者バッジの標準文字色 |
| `PLAY_SPEAKER_BG` | 話者バッジの標準背景色 |
| `PLAY_CHOICE_BG` | 選択肢ボタン背景 |
| `PLAY_CHOICE_HOVER` | 選択肢ホバー色 |

右上の `PRESET` では、`EDIT` 用に `DARK` / `LIGHT` / `SOFT` / `NOIR`、`PLAY` 用に `DARK` / `LIGHT` / `CINEMA` / `WARM` を適用できます。プリセットは保存前の設定へ反映されるだけなので、確定するには `SAVE` が必要です。

## SPEAKER COLORS

`SPEAKER COLORS` では、話者ごとの名前色と本文色を設定できます。キャラクターごとに色を変えると、誰が話しているかを読み取りやすくできます。

左側の `SPEAKERS` で対象を選び、中央のスロットを選んでから、右側の `MASTER PALETTE` をクリックして色を割り当てます。下側にはプレイ画面のダイアログプレビューが表示されます。

| 対象 | 設定できる色 |
| --- | --- |
| `[Narration]` | `TEXT (地の文)` |
| 登録した話者 | `NAME COLOR`、`NAME BG COLOR`、`TEXT COLOR` |

`ADD` で話者名を追加し、話者を選んだ状態で `DEL` を押すと削除できます。`[Narration]` は削除できません。

中央の `RESET SLOT (use default)` は、選択中スロットを未指定に戻します。未指定のスロットは `COLOR CONFIG` の標準色を使います。

画面下部の操作は次の通りです。

| ボタン | 動作 |
| --- | --- |
| `SAVE & CLOSE` | 設定を保存して閉じます。 |
| `REVERT` | 編集開始時点の設定に戻します。 |
| `CANCEL` / `ESC` | 保存せずに閉じます。未保存の変更がある場合は破棄確認が出ます。 |

話者ごとの色はゲーム実行中の本文色と話者バッジに反映されます。画像の減色時には、`COLOR CONFIG` の色と同じく予約色として扱われます。

## VN Palette Tool

`TOOLS` からVN Palette Toolを使えます。画像をPVNM向けの色味に整えたり、減色後の見え方を確認したりするための補助ツールです。

`SETTINGS` の `TOOLS` から `VN PALETTE TOOL` を押すと、別ウィンドウで起動します。PVNM本体とは別プロセスで動くため、画像変換をしながらエディタ側の作業も続けられます。

主な用途は次の通りです。

| タブ | できること |
| --- | --- |
| `CONVERT` | 1枚の画像をリサイズ、補正、減色して保存します。 |
| `BATCH` | フォルダ内の画像をまとめてリサイズ、必要に応じて減色します。 |
| `RENAME` | 元画像は変更せず、連番ファイル名でコピーします。 |

上部のボタンでは、画像、入力フォルダ、出力フォルダを選べます。下部の `SAVE CURRENT`、`BATCH CONVERT`、`RENAME COPY`、`CONVERT + RENAME` で保存や一括処理を実行します。

`CONVERT` の主な設定は次の通りです。

| 項目 | 内容 |
| --- | --- |
| 出力サイズ | `480x320` のような形式で指定します。 |
| アスペクト維持 | 縦横比を保って `contain` / `cover` で収めます。 |
| 倍率リサイズ | 元画像に対して倍率でサイズを調整します。 |
| リサイズ | `nearest`、`lanczos`、`bicubic` などを選びます。 |
| 補正プリセット | `AUTO`、`VIVID`、`SOFT`、`DARK CINEMA` などの補正をかけます。 |
| 色距離 | `Pillow標準`、`RGB`、`Weighted RGB`、`YCbCr`、`Lab` を選びます。 |
| ディザリング | `なし`、`Floyd-Steinberg`、`Ordered 2x2`、`Ordered 4x4` を選びます。 |
| ノイズ低減/後ノイズ/肌色補正/ピクセル化/輪郭強調/孤立除去 | 0-10で変換の効き具合を調整します。 |
| 指定色を透明化 | 白背景抜きなどに使います。透明化する色と許容値を指定します。 |
| 透明余白をトリミング | 透明部分の余白を切り詰めます。 |
| キャンバス固定 | 指定サイズのキャンバスに、左下/中央下/右下/中央で配置します。 |

パレット設定では、通常は `PVNM AUTO` のままで問題ありません。必要に応じて `CUSTOM .pyxpal` を選び、カスタムパレットを指定できます。

| 項目 | 内容 |
| --- | --- |
| `画像色` | `全256色` または `UI予約色を除外` を選びます。 |
| `UIプリセット` | `MASTER 0-15`、`CURRENT SETTINGS`、`EDIT ...`、`PLAY ...` から予約色の扱いを選びます。 |
| `色数` | 画像からカスタムパレットを作るときの抽出色数を選びます。 |
| `画像からカスタムパレット作成` | 現在の画像から `.pyxpal` を作成します。 |

`BATCH` の出力先を未選択にした場合、入力フォルダ内の `_pvnm_batch` に保存されます。`RENAME` の出力先を未選択にした場合は `_renamed` に保存されます。元画像は直接変更されません。

画像の最終的な見え方は、エディタ上のプレビューと書き出し後の実行環境で確認してください。特にWindows、Web、Androidでは表示環境が変わるため、配布前の実機確認を推奨します。
