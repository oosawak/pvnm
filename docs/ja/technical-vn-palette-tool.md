# VN Palette Tool詳細設計

このページでは、`vn_palette_tool.py` の各設定項目が内部で何をしているかを説明します。

操作の概要だけを知りたい場合は [色とツール](colors-and-tools.md) を参照してください。PVNM本体のシーンパレット、画像キャッシュ、エクスポート時の事前ビルドについては [減色・パレット・画像キャッシュ設計](technical-palette.md) を参照してください。

## 位置づけ

VN Palette Toolは、PVNM本体とは別プロセスで動く素材変換ツールです。ランタイムの自動シーンパレットとは役割が少し違います。

| 処理 | 目的 |
| --- | --- |
| PVNM本体のシーンパレット | 実行時に背景・立ち絵・UI色を1つのPyxelパレットへ収める |
| エクスポートの画像cache事前ビルド | 実行時のリサイズ/減色を避けるため、`.npy` index配列を先に作る |
| VN Palette Tool | 素材ファイル自体をリサイズ、補正、減色し、制作者が見た目を追い込む |

VN Palette Toolで保存したPNGは、通常の画像素材としてPVNMに読み込めます。つまり、このツールは「PVNMで扱いやすい素材へ前処理する」ためのものです。

## 変換パイプライン

`convert_image()` の処理順は次の通りです。

```text
入力画像をRGBA化
  ↓
透明部分のRGBを白で正規化し、元alphaからalpha maskを作る
  ↓
通常リサイズ、または倍率リサイズ
  ↓
指定色透明化をalpha maskへ反映
  ↓
補正プリセットをRGBへ適用
  ↓
alpha maskを戻す
  ↓
減色OFFならここで返す
  ↓
ピクセル化
  ↓
ノイズ低減
  ↓
肌色補正
  ↓
輪郭強調
  ↓
PVNM AUTOまたはCUSTOM .pyxpalでパレット決定
  ↓
色距離とディザリングに従って固定パレットへ写像
  ↓
後ノイズ低減
  ↓
alpha maskを戻す
  ↓
孤立除去
  ↓
alpha maskを戻す
  ↓
透明余白トリミング
  ↓
キャンバス固定
  ↓
出力PNG
```

重要なのは、透明判定が減色後ではなくリサイズ後・補正前に行われることです。ディザリングや減色で白背景周辺に色が散ってから透明化する方式ではないため、元alphaの透明余白は比較的壊れにくくなっています。

## 入出力

| 項目 | 内部処理 |
| --- | --- |
| `画像を選択` | `Image.open(path).convert("RGBA")` で読み、透明RGBを白で正規化 |
| `出力フォルダを選択` | 単体保存、パレット作成、BATCH、RENAMEの保存先候補になる |
| `SAVE CURRENT` | 現在画像を変換し、`pal_<元ファイル名>.png` で保存 |
| `BATCH CONVERT` | 一括入力フォルダ以下の対象画像をまとめて変換 |
| `RENAME COPY` | 元画像を変換せず、連番名でコピー |
| `CONVERT + RENAME` | 一括変換した結果を連番PNGで保存 |

単体保存では既存ファイルを上書きしません。`pal_image.png` があれば `pal_image_001.png` のように連番を付けます。

## 出力サイズ

`出力サイズ` は `480x320` のように指定します。内部では `parse_size()` が `x` で分割し、整数の幅と高さにします。

`倍率リサイズ` がOFFの場合、このサイズが通常変換の目標サイズです。

| アスペクト維持 | 収め方 | 処理 |
| --- | --- | --- |
| OFF | 無視 | 指定サイズへそのままリサイズ。縦横比は変わる |
| ON | `contain` | 指定サイズ内に収め、余白は透明キャンバスになる |
| ON | `cover` | 指定サイズを覆うように拡大/縮小し、はみ出しは中央基準で切る |

alpha maskは常に `NEAREST` でリサイズされます。半透明の境界を作らず、最終的に `alpha >= 128` を不透明、未満を透明へ二値化するためです。

## 倍率リサイズ

`倍率リサイズ` がONの場合、`出力サイズ` ではなく `元画像サイズ × 内部倍率` でサイズを決めます。

内部倍率は次の式です。

```text
scale = max(0.01, 1.0 + 指定% / 100)
```

例:

| 指定 | 内部倍率 | 結果 |
| --- | --- | --- |
| `-200%` | `0.01` | 1%まで縮小。0以下にはしない |
| `-50%` | `0.50` | 半分 |
| `0%` | `1.00` | 等倍 |
| `+100%` | `2.00` | 2倍 |
| `+200%` | `3.00` | 3倍 |

出力サイズを固定したいときは倍率リサイズをOFFにします。立ち絵を「元の縦横比のまま少し小さくする」ような用途ではONが向いています。

## リサイズ方式

`リサイズ` はPillowの `Image.Resampling` を選びます。

| 方式 | 内部値 | 特徴 |
| --- | --- | --- |
| `nearest` | `NEAREST` | 最近傍。最も硬い。ドット絵向き |
| `lanczos` | `LANCZOS` | 高品質縮小。細部を残すが、線の周囲にリンギングが出る場合がある |
| `bicubic` | `BICUBIC` | なめらかで少し柔らかい。キャラ絵で扱いやすい |
| `bilinear` | `BILINEAR` | さらに柔らかい。細かいノイズを平均化しやすい |
| `box` | `BOX` | 縮小時の平均化が強い。ざらつき抑制寄り |
| `hamming` | `HAMMING` | LanczosとBilinearの中間寄り |

減色前のリサイズ方式は、最終的なパレット選択に強く影響します。細い線やノイズが残るほど、減色時にその色へ枠を使いやすくなります。

## 補正プリセット

補正プリセットは、リサイズ後、減色前に適用されます。alphaは保持し、RGBだけを補正します。

| プリセット | 内部処理 |
| --- | --- |
| `NONE` | 補正なし |
| `AUTO` | `autocontrast(cutoff=1)`、Contrast `1.06`、Color `1.08` |
| `VIVID` | Color `1.28`、Contrast `1.12`、Sharpness `1.05` |
| `VIVID WARM` | Color `1.24`、Contrast `1.10`、R `1.06`、G `1.01`、B `0.94`、R offset `+3` |
| `VIVID COOL` | Color `1.22`、Contrast `1.10`、R `0.96`、G `1.01`、B `1.08`、B offset `+3` |
| `SOFT` | Color `0.92`、Contrast `0.94`、Brightness `1.04`、Sharpness `0.90` |
| `DARK CINEMA` | Brightness `0.88`、Contrast `1.20`、Color `0.90`、B `1.04` |

減色では、淡い差や低コントラスト部分が同じ色に吸収されやすくなります。`VIVID` 系は差を広げ、`SOFT` は差を抑え、`DARK CINEMA` は暗めのコントラストを作るための前処理です。

## 色距離

色距離は、各ピクセルをパレット内のどの色へ写像するかを決めます。

| 色距離 | 処理 |
| --- | --- |
| `Pillow標準` | Pillowの固定パレット `quantize(palette=...)` を使う |
| `RGB` | RGB空間の二乗距離で最近傍色を選ぶ |
| `Weighted RGB` | RGB距離に `R重み`、`G重み`、`B重み` を掛ける |
| `YCbCr` | RGBをY/Cb/Crへ変換し、重み `[1.25, 0.85, 0.85]` で距離計算 |
| `Lab` | RGBをLab空間へ変換し、Lab空間の二乗距離で最近傍色を選ぶ |

`Pillow標準` 以外は `custom_palette_map_fast()` で処理します。この関数は全ピクセルを直接パレットと比較せず、不透明ピクセルのユニークRGBだけを取り出してから最近傍計算します。

```text
不透明ピクセル
  ↓
unique RGB と inverse を作る
  ↓
unique RGBだけ色空間変換
  ↓
パレット色との距離をchunkごとに計算
  ↓
nearest色を決める
  ↓
inverseで全ピクセルへ展開
```

`Lab` はchunk size `4096`、それ以外は `8192` で分割して処理します。Lab変換は重いため、chunkを小さめにしています。

## R/G/B重み

`R重み`、`G重み`、`B重み` は、色距離が `Weighted RGB` のときだけ距離へ効きます。

距離は概念的に次の形です。

```text
distance =
  (dr * dr) * R重み
+ (dg * dg) * G重み
+ (db * db) * B重み
```

重みを大きくしたチャンネルは、その差をより嫌うようになります。たとえば `R重み` を上げると、赤成分の近さを強く守ります。肌色や夕焼けの赤みを残したい場合に使えますが、上げすぎると全体のバランスが崩れます。

`RGB`、`YCbCr`、`Lab`、`Pillow標準` では、この入力欄は実質使われません。

## ディザリング

ディザリングは、少ない色数で階調を感じさせるための処理です。

| モード | 内部処理 |
| --- | --- |
| `なし` | そのままパレットへ写像 |
| `Floyd-Steinberg` | `Pillow標準` のときだけ `Image.Dither.FLOYDSTEINBERG` を指定 |
| `Ordered 2x2` | 2x2行列でRGBに明暗オフセットを加えてから写像 |
| `Ordered 4x4` | 4x4行列でRGBに明暗オフセットを加えてから写像 |

Ordered 2x2の行列は次です。

```text
0 2
3 1
```

Ordered 4x4の行列は次です。

```text
0  8  2 10
12 4 14  6
3 11  1  9
15 7 13  5
```

各ピクセルでは、行列値から中心値を引き、RGBへオフセットを加えます。

```text
2x2: offset = (matrix[y % 2][x % 2] - 1.5) * 8
4x4: offset = (matrix[y % 4][x % 4] - 7.5) * 7
```

`RGB`、`Weighted RGB`、`YCbCr`、`Lab` の場合、Floyd-Steinbergは使われません。Ordered系だけが前処理として効きます。Floyd-Steinbergを使いたい場合は色距離を `Pillow標準` にします。

## パレット方式

### PVNM AUTO

`PVNM AUTO` は、現在の画像から自動的に256色パレットを作ります。

処理は次の通りです。

```text
MasterColor.pyxpal を読む
  ↓
UIプリセットから予約indexを決める
  ↓
予約indexのRGBを固定する
  ↓
画像の透明部分を予約index 0の色で合成
  ↓
最大辺256pxへ縮小
  ↓
Pillow Adaptive Paletteで候補色を抽出
  ↓
予約色と重複する候補を必要に応じて除外
  ↓
free slotへ詰める
```

これはPVNM本体のシーンパレット生成に近い考え方です。ただしツールでは1枚の変換対象画像を中心にパレットを作ります。

### CUSTOM .pyxpal

`CUSTOM .pyxpal` は、指定した `.pyxpal` の色を使います。ファイルは1行1色の `RRGGBB` 形式を基本とし、`#`、`;`、`//`、`key=value` 風の行にもある程度対応します。

読み込んだ色が256色未満の場合は、不足分を黒で埋めます。256色を超える場合は先頭256色だけを使います。

## 画像色

`画像色` は、画像ピクセルがUI予約indexを使ってよいかを決めます。

| 設定 | 挙動 |
| --- | --- |
| `全256色` | 画像ピクセルもUI予約indexを使える |
| `UI予約色を除外` | 画像ピクセルの候補からUI予約indexを外す |

`UI予約色を除外` の場合、`allowed_indices` は `0..255` から予約indexを除いた集合になります。Pillow標準で禁止indexへ落ちたピクセルは、許可index内の最近傍へ再マップされます。

PVNM AUTOでは、予約色と同じRGBをfree slot側へ重複配置できるようにしています。見た目としてその色を使える一方で、画像ピクセルはUI予約indexを使わない、という状態を作るためです。

## UIプリセット

UIプリセットは、どのindexを予約色として扱うかを決めます。

| 設定 | 予約対象 |
| --- | --- |
| `MASTER 0-15` | index `0..15` |
| `CURRENT SETTINGS` | `settings.json` の `dialog_role_indices` |
| `EDIT DARK/LIGHT/SOFT/NOIR` | エディタUIプリセットで使うrole index |
| `PLAY DARK/LIGHT/CINEMA/WARM` | プレイUIプリセットで使うrole index |

予約indexは、PVNM AUTOではマスターのRGBで固定されます。CUSTOM .pyxpalでも、UIプリセットが `MASTER 0-15` 以外なら、該当indexをマスター側のRGBで上書きします。

## 画像からカスタムパレット作成

`画像からカスタムパレット作成` は、現在の画像から `.pyxpal` を保存します。

| 項目 | 内容 |
| --- | --- |
| `色数` | `16`、`32`、`64`、`128`、`256` から選ぶ |
| `#FFFFFFを含める` | 先頭に白を予約し、抽出色数を1つ減らす |
| `並び順` | `なし`、`明るさ順`、`色相順` |
| `作成後このパレットを使用` | 保存した `.pyxpal` をすぐCUSTOMとして選択 |

抽出は、画像を白背景へ合成してRGB化し、Pillow Adaptive Paletteで指定色数を抽出します。`#FFFFFFを含める` がONの場合、白を先頭に置き、抽出色から重複白を除きます。

並び順の内部処理は次の通りです。

| 並び順 | sort key |
| --- | --- |
| `なし` | Pillowが返した順 |
| `明るさ順` | `0.299R + 0.587G + 0.114B`、同値ならRGB |
| `色相順` | RGBをHSVへ変換し、`H, S, V` でsort |

## 指定色を透明化

`指定色を透明化` は、元alphaとは別に、指定RGBに近いピクセルを透明にします。白背景抜きのための機能です。

処理はリサイズ後に行われます。

```text
target = 指定色RGB
tolerance = 0..80から選択
dist2 = (r-target_r)^2 + (g-target_g)^2 + (b-target_b)^2
dist2 <= tolerance^2 なら alpha = 0
```

UI上の選択肢は `0..10` と `15, 20, 25, ... 80` です。内部関数自体は `0..441` にclampしますが、UIからは最大80です。

| 値 | 意味 |
| --- | --- |
| `0` | 完全一致だけ透明化 |
| `1..10` | ごく近い色だけ抜く |
| `15..25` | JPEGノイズや白背景の薄いムラをある程度拾う |
| `30..50` | 背景抜きは強くなるが、白い服やハイライトも巻き込みやすい |
| `55..80` | かなり広範囲。特殊用途向き |

透明maskは最終的に二値化されます。半透明を保持する処理ではありません。

## ノイズ低減 0-10

`ノイズ低減` は、減色前に細かい色の散らばりを減らす処理です。実装は `reduce_noise_10level()` です。

処理は次の通りです。

```text
strength = level / 10
median_size = 3 if level <= 6 else 5
median = MedianFilter(median_size)
blur_radius = 0.05 + strength * 0.75
blurred = GaussianBlur(blur_radius)
alpha = min(0.85, 0.20 + strength * 0.65)
out = blend(original, blurred, alpha)
```

つまり、中央値フィルタで孤立した色をならし、軽いGaussian blurをかけ、それを元画像へ一定割合で混ぜます。

| level | strength | median | blur radius | blend alpha | 効き方 |
| --- | --- | --- | --- | --- | --- |
| 0 | - | - | - | - | 何もしない |
| 1 | 0.1 | 3 | 0.125 | 0.265 | ごく軽くざらつきを抑える |
| 2 | 0.2 | 3 | 0.200 | 0.330 | 軽いノイズを抑える |
| 3 | 0.3 | 3 | 0.275 | 0.395 | キャラ絵の減色前処理に使いやすい |
| 4 | 0.4 | 3 | 0.350 | 0.460 | 背景の細部を少しまとめる |
| 5 | 0.5 | 3 | 0.425 | 0.525 | グラデや写真系のざらつき抑制 |
| 6 | 0.6 | 3 | 0.500 | 0.590 | かなり滑らか |
| 7 | 0.7 | 5 | 0.575 | 0.655 | median範囲が広がり、細部が落ちやすい |
| 8 | 0.8 | 5 | 0.650 | 0.720 | 強い平滑化 |
| 9 | 0.9 | 5 | 0.725 | 0.785 | かなり強い |
| 10 | 1.0 | 5 | 0.800 | 0.850 | 最大。細部や線が眠くなりやすい |

この処理は減色前なので、パレット抽出と色距離の両方に影響します。ノイズが減るほど、似た色がまとまり、限られた色数を主要な面に使いやすくなります。

## 後ノイズ 0-10

`後ノイズ` は、減色後に出た点状のざらつきを軽くならす処理です。実装は `post_dither_noise_reduce_10level()` です。

処理は次の通りです。

```text
strength = level / 10
median = MedianFilter(3)
if level >= 7:
    median = GaussianBlur(0.15 + 0.25 * strength)
alpha = min(0.85, 0.15 + 0.60 * strength)
out = blend(quantized, median, alpha)
```

| level | strength | blur | blend alpha | 効き方 |
| --- | --- | --- | --- | --- |
| 0 | - | - | - | 何もしない |
| 1 | 0.1 | なし | 0.210 | 軽い点ノイズを抑える |
| 2 | 0.2 | なし | 0.270 | ディザ粒を少し丸める |
| 3 | 0.3 | なし | 0.330 | 立ち絵の粒を抑えやすい |
| 4 | 0.4 | なし | 0.390 | やや滑らか |
| 5 | 0.5 | なし | 0.450 | 背景の粒状感を抑える |
| 6 | 0.6 | なし | 0.510 | 強めの中央値寄せ |
| 7 | 0.7 | radius 0.325 | 0.570 | blurが加わる |
| 8 | 0.8 | radius 0.350 | 0.630 | 強い後処理 |
| 9 | 0.9 | radius 0.375 | 0.690 | 色境界も丸まりやすい |
| 10 | 1.0 | radius 0.400 | 0.750 | 最大。ディザ感は減るが眠くなる |

注意点として、後ノイズは減色後のRGBA画像へかかります。強くすると、せっかくパレットに寄せた色が中間色へ混ざり、使用色数が増える場合があります。PVNMのパレット感を厳密に保ちたい場合は低めにします。

## 肌色補正 0-10

`肌色補正` は、HSV条件で肌色らしいピクセルを探し、RGBを少し補正します。

肌色判定は次の条件です。

```text
5 <= hue_deg <= 55
0.08 <= saturation <= 0.65
0.35 <= value <= 1.0
r >= g >= b * 0.75
alpha > 0
```

補正量は次の式です。

```text
strength = level / 10
r += 10 * strength
g -=  3 * strength
b +=  5 * strength
```

| level | R | G | B | 傾向 |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 何もしない |
| 1 | +1.0 | -0.3 | +0.5 | ほぼ微調整 |
| 2 | +2.0 | -0.6 | +1.0 | 肌の血色を少し出す |
| 3 | +3.0 | -0.9 | +1.5 | キャラ立ち絵で使いやすい |
| 4 | +4.0 | -1.2 | +2.0 | 暖かさが増える |
| 5 | +5.0 | -1.5 | +2.5 | 強め |
| 6 | +6.0 | -1.8 | +3.0 | 肌色が目立つ |
| 7 | +7.0 | -2.1 | +3.5 | 暖色寄りが強い |
| 8 | +8.0 | -2.4 | +4.0 | かなり強い |
| 9 | +9.0 | -2.7 | +4.5 | 色味が変わりやすい |
| 10 | +10.0 | -3.0 | +5.0 | 最大 |

最終的には整数へclampされます。髪、木材、夕焼けなども条件に入ることがあるため、背景では0推奨です。

## ピクセル化 0-10

`ピクセル化` は、減色前に一度小さくしてから最近傍で戻す処理です。

```text
factor = 1.0 + (level / 10.0) * 4.0
small_w = int(width / factor)
small_h = int(height / factor)
small = resize(BILINEAR)
out = small.resize(original_size, NEAREST)
```

| level | factor | 小さくする比率 | 見た目 |
| --- | --- | --- | --- |
| 0 | - | - | 何もしない |
| 1 | 1.4 | 約71% | ごく軽いブロック感 |
| 2 | 1.8 | 約56% | 少しピクセル感 |
| 3 | 2.2 | 約45% | 輪郭が単純化 |
| 4 | 2.6 | 約38% | はっきりブロック化 |
| 5 | 3.0 | 約33% | 強め |
| 6 | 3.4 | 約29% | 細部が大きく落ちる |
| 7 | 3.8 | 約26% | かなり粗い |
| 8 | 4.2 | 約24% | 強いドット風 |
| 9 | 4.6 | 約22% | かなり抽象化 |
| 10 | 5.0 | 20% | 最大 |

この処理は色数を減らす前に形と色の細部をまとめるため、パレット化後のちらつきや細かなノイズを減らせます。普通の立ち絵では0か低め、ドット風へ寄せたい場合に上げます。

## 輪郭強調 0-10

`輪郭強調` は、減色前にUnsharp Maskをかける処理です。実装は `sharpen_edges_10level()` です。

```text
strength = level / 10
radius = 1.0 + strength * 1.2
percent = int(60 + strength * 220)
threshold = max(0, int(6 - strength * 5))
blend_alpha = min(1.0, 0.25 + strength * 0.75)
sharp = UnsharpMask(radius, percent, threshold)
out = blend(original, sharp, blend_alpha)
```

| level | radius | percent | threshold | blend | 傾向 |
| --- | --- | --- | --- | --- | --- |
| 0 | - | - | - | - | 何もしない |
| 1 | 1.12 | 82 | 5 | 0.325 | 軽く線を立てる |
| 2 | 1.24 | 104 | 5 | 0.400 | 少しシャープ |
| 3 | 1.36 | 126 | 4 | 0.475 | キャラ絵で使いやすい |
| 4 | 1.48 | 148 | 4 | 0.550 | 線が目立つ |
| 5 | 1.60 | 170 | 3 | 0.625 | 強め |
| 6 | 1.72 | 192 | 3 | 0.700 | 輪郭がかなり立つ |
| 7 | 1.84 | 214 | 2 | 0.775 | ハイライト周辺も強調 |
| 8 | 1.96 | 236 | 2 | 0.850 | ノイズも拾いやすい |
| 9 | 2.08 | 258 | 1 | 0.925 | 強い |
| 10 | 2.20 | 280 | 1 | 1.000 | 最大 |

輪郭強調は、減色後に線が溶ける問題を抑えます。一方で、強くすると線の周囲に別色が増え、パレット枠を消費しやすくなります。

## 孤立除去 0-10

`孤立除去` は、減色後に周囲から浮いた点を周辺の多数色へ置き換える処理です。

処理は3x3近傍で行います。

```text
strength = level / 10
threshold = max(2, round(8 - strength * 6))
repeat = 1 if level <= 5 else 2

中心ピクセルと周囲8ピクセルを見る
透明ピクセルは無視
周囲で最も多い色の個数 >= threshold かつ中心と違う
  → 中心をその多数色へ置換
```

| level | threshold | repeat | 置換条件 |
| --- | --- | --- | --- |
| 0 | - | - | 何もしない |
| 1 | 7 | 1 | 周囲8個中7個以上が同色 |
| 2 | 7 | 1 | 周囲8個中7個以上が同色 |
| 3 | 6 | 1 | 周囲8個中6個以上が同色 |
| 4 | 6 | 1 | 周囲8個中6個以上が同色 |
| 5 | 5 | 1 | 周囲8個中5個以上が同色 |
| 6 | 4 | 2 | 条件が緩くなり、2回通す |
| 7 | 4 | 2 | 強め |
| 8 | 3 | 2 | 小さな模様も消えやすい |
| 9 | 3 | 2 | かなり強い |
| 10 | 2 | 2 | 最大。細部を潰しやすい |

この処理は減色後の点ノイズに効きます。目のハイライト、アクセサリ、細い模様なども孤立色として消える場合があるため、キャラ絵では1〜3程度から確認するのが安全です。

## 透明余白をトリミング

`透明余白をトリミング` は、alpha maskのbboxで画像とmaskをcropします。

```text
bbox = alpha.getbbox()
if bbox:
    img = img.crop(bbox)
    alpha = alpha.crop(bbox)
```

完全透明の周辺余白を削るため、立ち絵素材の当たり判定や配置用画像を小さくできます。PVNM上で座標や表示サイズを合わせている素材に使う場合は、基準位置が変わる点に注意してください。

## キャンバス固定

`キャンバス固定` は、変換後画像を指定サイズの透明キャンバスへ配置します。

| 配置 | x | y |
| --- | --- | --- |
| `左下` | `0` | `canvas_h - image_h` |
| `中央下` | `(canvas_w - image_w) // 2` | `canvas_h - image_h` |
| `右下` | `canvas_w - image_w` | `canvas_h - image_h` |
| `中央` | `(canvas_w - image_w) // 2` | `(canvas_h - image_h) // 2` |

立ち絵の足元を揃えたい場合は `中央下` や `左下` が向きます。キャンバスより画像が大きい場合のcrop専用処理はなく、Pillowの合成範囲に依存します。

## プレビュー倍率

`元画像倍率` と `変換後倍率` はプレビュー表示だけに効きます。保存画像のサイズには影響しません。

プレビュー画像は `NEAREST` で拡大縮小し、透明部分はチェック柄背景へ合成されます。減色後のピクセルや透明抜けを確認しやすくするためです。

## 使用色数

変換後ステータスに出る `使用色` は、不透明ピクセルのRGB集合を数えます。

```text
img.convert("RGBA").getcolors(maxcolors=999999)
alpha > 0 の色だけ set に入れる
```

パレットindex数ではなくRGBの種類数です。後ノイズなどで中間色が増えた場合、この値も増えます。

## BATCH

BATCHは、一括入力フォルダ以下の画像を再帰的に処理します。対象拡張子は次です。

```text
.png .jpg .jpeg .webp .bmp
```

出力はPNGです。出力先未選択の場合、入力フォルダ内の `_pvnm_batch` に保存します。`_pvnm_batch`、`_renamed`、出力先フォルダは検索対象から除外されます。

| 項目 | 内容 |
| --- | --- |
| `サイズ` | `720x480`、`360x240`、`180x120` |
| `減色も実行` | ONならCONVERTの減色設定を使う。OFFならリサイズ/補正/透明処理まで |
| `小さい画像は拡大しない` | ONなら目標サイズより小さい画像を拡大しない |
| `一括実行` | 変換して `_pvnm_batch` または出力先へ保存 |
| `変換＋リネーム` | RENAMEタブの連番ルールで変換後PNGを保存 |

BATCHでは、通常の `出力サイズ` ではなくBATCHタブの `サイズ` を使います。画像は目標サイズ内に収まるようにリサイズされ、アスペクト比は維持されます。

`減色も実行` がOFFでも、補正プリセットや透明化など、減色前までの処理は通ります。パレット適用以降だけがスキップされます。

## 画像ごとの個別設定

BATCHのファイル一覧は複数選択できます。選択中に設定を変えると、その項目だけが選択ファイルの個別設定として記録されます。

内部では次のように管理します。

```text
global_settings: 全体設定
per_file_settings[path].values: 画像ごとの値
per_file_settings[path].touched: 個別に触った項目名
```

一覧では、個別設定がある画像に `[*]` が付きます。個別設定がない画像は `[ ]` です。

BATCH実行時は、まず全体設定を取り、`touched` に入っている項目だけ画像ごとの値で上書きします。これにより、特定の画像だけ色距離や透明許容を変える、といった運用ができます。

## RENAME

RENAMEは、元画像を変更せずに連番名でコピーします。

| 項目 | 内容 |
| --- | --- |
| `ベース名` | 出力名の先頭。禁止文字 `<`、`>`、`:`、`"`、`/`、バックスラッシュ、縦棒、`?`、`*` と制御文字は `_` へ置換 |
| `開始` | 連番の開始番号。0以上 |
| `桁数` | `4`、`5`、`6`。内部的には4以上が必要 |
| `順` | `ファイル名順` または `更新日時順` |
| `対象` | 一覧全体、または選択分 |
| `プレビュー` | 変換前後のファイル名対応を表示 |
| `コピー実行` | 元ファイルを連番名でコピー |

例:

```text
ベース名 image
開始 1
桁数 4

image_0001.png
image_0002.png
image_0003.png
```

コピー先に既存ファイルがある場合は実行前にエラーにします。上書きはしません。

## CONVERT + RENAME

`CONVERT + RENAME` は、BATCHの変換処理とRENAMEの命名規則を組み合わせます。

| 参照する設定 | 内容 |
| --- | --- |
| CONVERT | 補正、色距離、ディザリング、透明化、パレットなど |
| BATCH | サイズ、減色ON/OFF、小さい画像を拡大しない |
| RENAME | ベース名、開始番号、桁数、順、対象 |

出力は必ずPNGです。元ファイルは変更しません。コピー先に既存ファイルがある場合は、通常のRENAMEと同じく実行前に止まります。

## 推奨値の考え方

キャラ立ち絵では、肌や目の小さな情報を残しつつ、透明縁のノイズを抑える必要があります。

| 用途 | 推奨の出発点 |
| --- | --- |
| キャラ立ち絵 | 色距離 `Lab`、Ordered 4x4、ノイズ低減 `1..3`、肌色補正 `2..5`、輪郭強調 `0..2`、後ノイズ `1..3`、孤立除去 `1..3` |
| 背景 | 色距離 `Pillow標準` または `Lab`、Floyd-SteinbergまたはOrdered 4x4、ノイズ低減 `3..6`、肌色補正 `0`、輪郭強調 `0..1`、後ノイズ `2..5`、孤立除去 `2..4` |
| ドット絵 | リサイズ `nearest`、ピクセル化低めまたは0、ディザなし、後処理弱め |
| 白背景抜き立ち絵 | 指定色透明化ON、透明許容 `10..25` から確認 |

強い処理を重ねると、見た目はまとまりますが、元絵の細部は失われます。まず低い値で確認し、必要な項目だけ上げる方が安定します。

## 注意点

| 注意点 | 理由 |
| --- | --- |
| 後ノイズを強くすると使用色数が増える場合がある | 減色後の色同士をblendするため |
| 孤立除去を強くすると小さなハイライトが消える | 周囲多数色へ置換するため |
| 肌色補正は背景にも反応する場合がある | HSV条件に木材や夕焼けが入ることがある |
| `UI予約色を除外` は使える画像色数を減らす | 予約indexを画像候補から外すため |
| CUSTOM .pyxpal は作品全体の統一感には強いが画像単体最適ではない | パレットが固定されるため |
| BATCHの個別設定は触った項目だけ上書きする | 画像ごとに意図しない設定差が残る場合がある |
