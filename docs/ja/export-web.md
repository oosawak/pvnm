# Web HTMLエクスポート

Web HTMLエクスポートは、ブラウザで動く形式を書き出します。

## 出力

`[WEB HTML]` を実行すると、次のような成果物が生成されます。

| 出力 | 内容 |
| --- | --- |
| `.html` | 起動用HTML |
| `<name>_assets/` | Web実行に必要な素材 |
| `pyxel/` | ローカル化されたPyxel Webランタイム |

HTMLだけでは素材やランタイムを読み込めません。配布するときは、HTML、`<name>_assets/`、`pyxel/` を同じ関係で配置してください。

プロジェクトに `assets/images/ui/loading.png` がある場合、Web版の起動中ローディング画像として使われます。詳しくは [素材と音声](assets-and-audio.md) を見てください。

## 用途

| 用途 | 説明 |
| --- | --- |
| GitHub Pages | Webページ上でプレイさせたい場合 |
| itch.ioなど | ブラウザゲームとして配布したい場合 |
| ローカル確認 | ブラウザで動作を確認したい場合 |

## ローカル確認

ブラウザの制限により、HTMLファイルを直接開くより、ローカルサーバー経由で確認するほうが安定します。

```bash
python3 -m http.server 8133
```

その後、ブラウザで `http://127.0.0.1:8133/<書き出したhtml名>` を開いて確認します。

## 配布

GitHub Pagesなどに置く場合は、`.html`、`<name>_assets/`、`pyxel/` をまとめて配置します。GitHub ReleasesでWeb版を配布する場合は、この3つを同じ階層構造のままzip化してRelease Assetにします。

## 配布前の確認

Webでは、画像、音声、セーブデータ、EXTRASの開放状態などがデスクトップ版と異なる条件で動くことがあります。配布先に置いた状態で、最初からエンディングまで確認してください。
