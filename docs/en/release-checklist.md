# Release Checklists

PVNM has two different release checklists.

Japanese version: [公開前チェックリスト](../ja/release-checklist.md)

| Target | Checklist |
| --- | --- |
| A game exported from PVNM | [Game Release Checklist](work-release-checklist.md) |
| PVNM itself | [PVNM Release Checklist](pvnm-release-checklist.md) |

Use the game checklist when you are publishing zip/APK/Web files created by PVNM. Use the PVNM checklist when you are publishing this tool's source code or packaged application.
